## FAQ

<details><summary>What is an asset management tool?</summary>
Automated software that tracks an organization's IT assets, from procurement to retirement, in one database.
</details>
<details><summary>What is the difference between an IT asset and a configuration item?</summary>
In ITIL, an asset is anything with financial value to the business, while a configuration item (CI) is a component that must be managed to deliver an IT service. Many assets are also CIs.
</details>
<details><summary>How can software asset management reduce costs?</summary>
By showing which licenses are actually used, it helps you avoid over-buying and stay compliant during audits.
</details>
