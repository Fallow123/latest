- q: What does AEM mean?
  a: AEM means autonomous endpoint management. It is a set of tools for controlling and protecting an organization’s employee devices and servers from a single location within the IT department, using AI and automation to discover, patch and fix devices with less manual work.
- q: What is an endpoint management system?
  a: It is software that helps IT managers perform remote management tasks on users’ endpoint devices, including discovering, updating, troubleshooting, patching, and provisioning them.
- q: What is an AEM solution?
  a: This refers to autonomous endpoint management software that integrates common endpoint management features with other IT systems. These tools can help IT to manage and protect devices, software, data, and users.
- q: Why is endpoint security important?
  a: An organization’s devices, particularly when in remote locations, are vulnerable to cybersecurity threats. Endpoint security tools can protect them from threats and remediate them after attacks.
- q: How does endpoint security work?
  a: An organization’s endpoint security software maintains and updates a centralized database of current possible threats. The system then pushes relevant security solutions out to affected devices, as well as scanning for threats in the flow of files through the network.
- q: What is a system endpoint?
  a: An endpoint is any device or virtual device that is served by an organization’s network. This can include devices that are connected to an organization through the cloud.
- q: Is a server an endpoint?
  a: Any device can be an endpoint if it is connected to an organization’s network. A server can be an endpoint, along with desktop computers, laptops, mobile devices, and others.
- q: What is advanced endpoint protection?
  a: Traditional endpoint protection software only reacts to known threats, such as current viruses. But advanced endpoint protection uses machine learning to additionally protect endpoints from novel threats.

## Manage all your devices in one place

What is endpoint management software? It’s a comprehensive tool for IT departments to oversee all user devices via one console. The software shows every device—even if they’re running different operating systems—including desktops, laptops, servers, virtual environments, and mobile devices.

With Ivanti’s Autonomous Endpoint Management, you will be able to:

- Automatically compile an accurate list of all devices connected to your network, along with their software
- Send out new software and patches automatically to appropriate devices
- Update entire operating systems on devices automatically
- Manage user profiles between multiple devices
- See all your endpoint management data in visual reports, with data normalization tools making diverse data understandable
- Update and enforce policies
- Take remote control of devices, when necessary
- Fight security threats on remote devices more easily
- Manage Windows, Mac, Android, iOS, and Linux devices from one console

These endpoint management solutions can save your IT personnel significant time, which they can put toward improvements to their department and your organization. You may even be able to let a single person manage all the devices in the whole enterprise.
